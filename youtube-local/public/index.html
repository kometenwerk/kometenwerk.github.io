🎬 YouTube-Upload für Kometenwerk

Dieser Helfer läuft nur auf deinem PC. Neue Videos werden immer privat hochgeladen. Prüfe sie in YouTube Studio und veröffentliche sie dort selbst.

1. OAuth-Datei einrichten

Verbindungsstatus wird geprüft …

Die Datei wird direkt an diesen lokalen Helfer auf deinem PC übergeben und außerhalb des Website-Ordners gespeichert.

2. Kanal verbinden

Mit Google verbinden

Im Google-Fenster das Konto auswählen, das den YouTube-Kanal verwaltet. Die App fragt nur nach YouTube-Uploadzugriff. Das Google-Passwort wird nicht an diese App weitergegeben.

3. Video privat hochladen

Der Link https://kometenwerk.github.io/ wird automatisch angehängt, falls er noch fehlt.

Das Video wird nur privat hochgeladen.

Zugangsdaten und Anmeldetoken liegen außerhalb des Website-Ordners unter deinem Windows-Benutzerkonto. Auf GitHub wird nichts davon gespeichert.
