Kometenwerk Code

Arduino programmieren – auf Deutsch erklärt

Kostenloses PC-Programm wie die Arduino IDE, nur verständlicher. Ohne Werbung, ohne Konto.

  • Fehler auf Deutsch: „brind gibt es nicht – meintest du begin?“
  • Serieller Monitor mit Diagramm, Messwerten und Verbindungs-Test
  • Befehls-Lexikon (F1) mit Beispielen
  • Projekt-Tagebuch, Teileliste und Fehler-Sammlung für NWT-Projekte
  • Zeichnen mit Maßen in mm/cm, passend aufs A4-Blatt – direkt weiter an FIDELIA Notizen
  • Automatische Sicherung und Updates im Programm

🪟 Windows – mit Installation (empfohlen)⬇ 🪟 Windows – ohne Installation (z. B. Schul-PC)⬇ 🐧 Linux (AppImage)⬇
